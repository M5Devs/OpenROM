## Bundled Tools

### chdman
**Project:** MAME — Multiple Arcade Machine Emulator
**Authors:** The MAME Team (original author: Nicola Salmoria)
**License:** GPL-2.0-or-later
**Repository:** https://github.com/mamedev/mame

chdman is the official CHD (Compressed Hunks of Data) manager from the MAME project.
It powers all CHD creation and extraction in OpenROM.

---

### maxcso
**Author:** unknownbrackets
**License:** ISC License
**Repository:** https://github.com/unknownbrackets/maxcso

maxcso is a fast CSO/ZSO compressor for PSP and PS2 ISO files.
It powers all CSO conversion in OpenROM.

---

### ecm / unecm
**Author:** Neill Corlett
**License:** GPL-2.0
**Website:** http://www.neillcorlett.com/ecm/

ECM (Error Code Modeler) is a lossless compression tool for CD images.
It powers all ECM encoding and decoding in OpenROM.

---

### extract-xiso
**Author:** in (in@fishtank.com)
**Maintainer:** XboxDev community
**License:** GPL-2.0
**Repository:** https://github.com/XboxDev/extract-xiso

extract-xiso is the original Xbox ISO creation and extraction utility.
As of v4.0.0 it is distributed as a community `.orplug` extension rather than
bundled with OpenROM Core.

---

### nodtool (nod)
**Author:** Luke Street (encounter)
**License:** MIT / Apache-2.0
**Repository:** https://github.com/encounter/nod

nodtool is a Rust-based CLI tool for reading and converting Nintendo GameCube
and Wii disc images (ISO, RVZ, WIA, WBFS, GCZ).
It powers all GameCube/Wii format conversion in OpenROM.
